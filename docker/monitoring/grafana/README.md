# Remal Spring Box: Grafana image

## 1) Overview
Grafana is an industry-leading, open-source analytics and visualization platform designed to query, explore, visualize, and generate alerts based on data stored in time-series databases and other external platforms.

## 2) Image details
* Installation of the Grafana server.
* Pre-configured Grafana Data Source to automatically connect with the dedicated Prometheus metrics endpoint in the Remal Spring Box ecosystem.

## 3) Exposed ports
* **22 (TCP):** Secure Shell (SSH) management access.
* **1331 (TCP):** Readiness signal port
* **3000 (TCP):** The industry-standard default network port used by the Grafana server to handle all inward traffic.
